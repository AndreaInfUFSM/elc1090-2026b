ELC1090 · Supabase

Backend como serviço

Aqui o navegador conversa diretamente com Supabase Auth e com a API de dados. A autorização das linhas acontece por políticas RLS no PostgreSQL.

Configuração ausente.

Copie .env.example para .env e informe URL e chave publicável do projeto Supabase.

Login

Crie os usuários de teste no painel Auth do seu projeto Supabase.

Usuário

As consultas retornam apenas as tarefas deste usuário por causa da RLS.

    O que observar 
    Frontend → Supabase Auth
Frontend → Data API → PostgreSQL
                    ↳ RLS verifica auth.uid()

Não existe um Express/FastAPI/Spring escrito por nós neste exemplo.
