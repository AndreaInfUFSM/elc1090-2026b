# Primeiro projeto

> Objetivo: "Remake" de uma aplicação web simples, conforme demanda de cliente


Remake? Simples?

- Código disponível, para estudo e comparação
- Aplicação 100% client-side ou com backend mínimo
- Diferenças ou semelhanças deverão se guiar por: demanda de cliente (analisada criticamente) e ideia/curiosidade de quem irá implementar
- Código recriado do zero ou muito modificado (não se trata de alterar somente uma linha de CSS)
- Funcionalidades podem ser alteradas/adicionadas, mas não removidas 

O que você vai aprender/exercitar neste projeto?

- Aplicar as tecnologias básicas que compõem a web, principalmente HTML, CSS e JavaScript, e também o processo de hospedagem/deploy de uma aplicação web simples





## Recursos permitidos
 
- Básico: HTML, CSS, JavaScript
- Bibliotecas, templates
- Uso inteligente de IA: aproveite geradores de código para ajudar no trabalho e aprender, não para se livrar rapidamente do trabalho; o processo de desenvolvimento e aprendizado precisará gerar evidências
- Opcional: front-end frameworks (React, Vue, etc.) - especialmente para quem se interessar em fazer um trabalho comparativo


## Desenvolvimento

Etapas:

- obtenção do código
- teste local e publicação online da versão original, no seu repositório próprio (será criado automaticamente)
- remake
  - estrutura; código HTML
  - estilo: código CSS
  - comportamento: código JavaScript
- teste local e publicação online da nova versão

## Entrega


- Use o repositório de entrega que será criado automaticamente

- Faça commits frequentes, seguindo boas práticas

- Preencha o README que já virá junto com o repositório

- Prepare-se para uma apresentação do projeto com duração de 3 a 5 minutos, com ênfase no processo de desenvolvimento.

- Prazos:

  - Entrega até 24/08, apresentações dias 25 e 27/08.

- Avaliação: veja rubricas/critérios de avaliação no próximo slide
